# Sobre a Ferramenta

Esta ferramenta online é a evolução de um projeto meu já existente no GitHub, chamado **Arena Breakout Infinite - Database Offline (ABIDB)**. 

A transição para o formato *web* foi motivada pelo feedback da comunidade: muitos usuários me relataram que achariam mais prático e se sentiriam mais seguros se o aplicativo rodasse diretamente no navegador, sem precisar baixar executáveis. Essa mudança também foi excelente para o desenvolvimento, pois a plataforma web possui menos limitações que o PowerShell, o que me possibilitou introduzir o suporte ao idioma inglês e diversas melhorias de interface.

Como todo o código original pertencia ao PowerShell, utilizei a inteligência artificial do Gemini para auxiliar na portabilidade do código, o que acelerou o início deste novo projeto e facilitou imensamente o meu trabalho.

### Coleta de Dados e Precisão
Todos os dados contidos nesta ferramenta (atributos, balística, compatibilidade, etc.) são coletados e testados rigorosamente de forma manual. Esse esforço garante que as informações aqui exibidas condigam exatamente com a realidade do jogo.

### O Futuro da Ferramenta
Desenvolvo este projeto como um passatempo e pela pura vontade de ajudar a comunidade. Meu compromisso é manter a ferramenta viva, trazendo atualizações para o banco de dados sempre que possível, para melhorar a experiência e adicionar novos conteúdos.

### Feedback e Avisos Importantes
Se você encontrar algum erro de valor, nomenclatura ou qualquer outra divergência nos dados, peço encarecidamente que **teste e confirme a informação manualmente dentro do jogo** antes de me enviar uma notificação. 

Além disso, peço que seja educado ao relatar problemas. Mensagens desrespeitosas ou exigências sem verificação prévia serão ignoradas.
