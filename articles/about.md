# About the Tool

This online tool is the evolution of an existing GitHub project of mine called **Arena Breakout Infinite - Database Offline (ABIDB)**.

The transition to the *web* format was driven by community feedback: many users told me they would find it more practical and feel safer if the application ran directly in the browser, without the need to download executables. This change was also excellent for development, as the web platform has fewer limitations than PowerShell, allowing me to introduce English language support and several interface improvements.

Since all the original code belonged to PowerShell, I used Gemini's artificial intelligence to assist in porting the code. This accelerated the start of this new project and immensely facilitated my workflow.

### Data Collection and Accuracy
All data contained in this tool (attributes, ballistics, compatibility, etc.) is collected and rigorously tested manually. This effort ensures that the information displayed here matches the game's reality exactly.

### The Future of the Tool
I develop this project as a hobby and out of a pure desire to help the community. My commitment is to keep the tool alive, bringing updates to the database whenever possible to improve the experience and add new content.

### Feedback and Important Notices
If you find any value error, naming mistake, or any other data discrepancy, I strongly ask that you **manually test and confirm the information in-game** before sending me a notification.

Additionally, please be polite when reporting issues. Disrespectful messages or demands without prior verification will be ignored.

**A note on communication:** *My native language is Portuguese. However, if you message me in English, I will understand about 97% of what you write, provided you avoid using heavy slang.*
